۱

پیش‌نیازها و شرایط لازم

قبل از شروع انتشار پروژه Vue 3 در GitHub Pages، مطمئن شوید که ابزارهای زیر را روی سیستم خود نصب دارید:

①
Node.js نسخه ۱۸ یا بالاتر

برای اجرای پروژه و مدیریت بسته‌ها نیاز به Node.js دارید.

terminal 
# بررسی نسخه Node.js
node --version

# بررسی نسخه npm
npm --version
②
Git نصب شده

برای مدیریت نسخه و ارسال کد به گیت‌هاب به Git نیاز دارید.

③
حساب کاربری گیت‌هاب

یک حساب رایگان در github.com داشته باشید.

💡 نکته

اگر هنوز Node.js را نصب ندارید، از سایت رسمی nodejs.org نسخه LTS را دانلود و نصب کنید.

۲

ساخت پروژه Vue 3 با Vite

با استفاده از دستور زیر یک پروژه جدید Vue 3 با ابزار Vite بسازید:

terminal 
# ساخت پروژه جدید Vue 3
npm create vite@latest my-vue-app -- --template vue

# ورود به پوشه پروژه
cd my-vue-app

# نصب وابستگی‌ها
npm install

# اجرای پروژه در حالت توسعه
npm run dev

بعد از اجرای دستور بالا، پروژه شما در آدرس http://localhost:5173 اجرا می‌شود.

✅ خوب است بدانید

Vite ابزار ساخت و باندل پروژه‌های فرانت‌اند است که سرعت بالایی در توسعه و ساخت (build) دارد و جایگزین Webpack در پروژه‌های Vue 3 شده است.

۳

ساخت مخزن (Repository) در گیت‌هاب

مراحل زیر را برای ساخت یک مخزن جدید در GitHub دنبال کنید:

۱
وارد حساب گیت‌هاب خود شوید

به آدرس github.com بروید و وارد شوید.

۲
مخزن جدید بسازید

روی دکمه + در بالای صفحه و سپس New repository کلیک کنید.

۳
نام مخزن را وارد کنید

نام مخزن باید با فرمت username.github.io باشد تا به عنوان سایت اصلی شما عمل کند، یا هر نام دیگری برای پروژه‌های فرعی.

💡 نکته درباره نام مخزن

اگر نام مخزن را username.github.io بگذارید (جایی که username نام کاربری شماست)، سایت شما در آدرس https://username.github.io نمایش داده می‌شود. اگر نام دیگری مثل my-project بگذارید، آدرس سایت https://username.github.io/my-project خواهد بود.

۴
مخزن را خالی نگه دارید

گزینه‌های اضافی مثل README یا .gitignore را فعال نکنید. مخزن کاملاً خالی باشد.

۴

ارسال کد به گیت‌هاب

حالا باید کد پروژه خود را به مخزن گیت‌هاب ارسال کنید. دستورات زیر را در ترمینال و در پوشه پروژه اجرا کنید:

terminal 
# مقداردهی اولیه مخزن گیت
git init

# اضافه کردن تمام فایل‌ها
git add .

# ایجاد اولین کامیت
git commit -m "اولین کامیت - پروژه Vue 3"

# تنظیم شاخه اصلی
git branch -M main

# اضافه کردن مخزن ریموت (نام کاربری خود را جایگزین کنید)
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git

# ارسال کد به گیت‌هاب
git push -u origin main
⚠️ مهم

به جای YOUR-USERNAME نام کاربری گیت‌هاب خود و به جای YOUR-REPO-NAME نام مخزنی که ساختید را وارد کنید.

احراز هویت با GitHub CLI (اختیاری)

اگر با مشکل احراز هویت مواجه شدید، می‌توانید از GitHub CLI استفاده کنید:

terminal 
# نصب GitHub CLI
sudo apt install gh

# ورود به حساب
gh auth login
۵

تنظیم مسیر پایه (Base Path)

یکی از مهم‌ترین مراحل، تنظیم base در فایل vite.config.js است. این تنظیم مشخص می‌کند که فایل‌های پروژه در چه مسیری قرار می‌گیرند.

حالت ۱: پروژه اصلی (username.github.io)

اگر نام مخزن شما username.github.io باشد:

📄 vite.config.js
javascript 
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  base: '/',  // برای پروژه اصلی
})

حالت ۲: پروژه فرعی (username.github.io/my-project)

اگر نام مخزن شما مثلاً my-project باشد:

📄 vite.config.js
javascript 
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  base: '/my-project/',  // نام مخزن خود را اینجا قرار دهید
})
⚠️ نکته حیاتی

اگر base را به درستی تنظیم نکنید، تمام فایل‌های CSS، JavaScript و تصاویر پروژه شما یافت نخواهند شد و صفحه سفید می‌بینید!

روش خودکار (پیشنهادی)

می‌توانید base را بر اساس محیط اجرا تنظیم کنید:

📄 vite.config.js
javascript 
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  base: process.env.NODE_ENV === 'production' 
    ? '/my-project/' 
    : '/',
})
۶

استقرار با بسته gh-pages

ساده‌ترین روش برای انتشار پروژه Vue 3 در GitHub Pages، استفاده از بسته gh-pages است.

مرحله ۱: نصب بسته gh-pages

terminal 
npm install -D gh-pages

مرحله ۲: اضافه کردن اسکریپت به package.json

📄 package.json
json 
{
  "name": "my-vue-app",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "predeploy": "npm run build",
    "deploy": "gh-pages -d dist"
  },
  "dependencies": {
    "vue": "^3.4.0"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^5.0.0",
    "gh-pages": "^6.1.0",
    "vite": "^5.0.0"
  }
}
💡 توضیح اسکریپت‌ها

predeploy: قبل از اجرای deploy، به صورت خودکار اجرا می‌شود و پروژه را build می‌کند.

deploy: محتوای پوشه dist را به شاخه gh-pages ارسال می‌کند.

مرحله ۳: اجرای استقرار

terminal 
# اجرای استقرار
npm run deploy

بعد از اجرای این دستور، پروژه شما به صورت خودکار build شده و در GitHub Pages منتشر می‌شود.

۷

استقرار با GitHub Actions (روش پیشرفته)

روش حرفه‌ای‌تر استفاده از GitHub Actions است که به صورت خودکار پروژه شما را در هر بار push به شاخه main build و deploy می‌کند.

مرحله ۱: فعال‌سازی GitHub Pages

در صفحه مخزن خود در گیت‌هاب:

  1. به بخش Settings بروید
  2. از منوی سمت راست روی Pages کلیک کنید
  3. در بخش Source گزینه GitHub Actions را انتخاب کنید

مرحله ۲: ساخت فایل Workflow

فایل زیر را در مسیر .github/workflows/deploy.yml بسازید:

📄 .github/workflows/deploy.yml
yaml 
name: Deploy Vue 3 to GitHub Pages

on:
  push:
    branches: [ "main" ]

  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build with Vite
        run: npm run build

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
✅ مزایای GitHub Actions
  • استقرار خودکار در هر بار push به شاخه main
  • نیازی به نصب بسته gh-pages نیست
  • امکان استقرار چند پروژه با workflow‌های جداگانه
  • مدیریت نسخه و تاریخچه استقرار

۱۰

عیب‌یابی و مشکلات رایج

❌ صفحه سفید نمایش داده می‌شود

🔍 علت احتمالی

تنظیم base در فایل vite.config.js اشتباه است.

راه‌حل: مقدار base را مطابق با نام مخزن خود تنظیم کنید. (بخش ۵ را مرور کنید)

❌ فایل‌های CSS و JS یافت نمی‌شوند

🔍 علت احتمالی

مسیرهای مطلق در کد شما با GitHub Pages سازگار نیستند.

راه‌حل: از مسیرهای نسبی استفاده کنید و مطمئن شوید base به درستی تنظیم شده است.

❌ خطا در مسیرهای روتینگ (Router)

🔍 علت احتمالی

اگر از Vue Router با حالت history استفاده می‌کنید، GitHub Pages از آن پشتیبانی نمی‌کند.

راه‌حل: از حالت hash در Vue Router استفاده کنید:

📄 src/router/index.js
javascript 
import { createRouter, createWebHashHistory } from 'vue-router'

const router = createRouter({
  history: createWebHashHistory(),  // ← استفاده از hash mode
  routes: [
    // مسیرهای خود را اینجا تعریف کنید
  ]
})

export default router

❌ خطای 404 هنگام بارگذاری مستقیم صفحات

💡 راه‌حل

GitHub Pages فقط فایل index.html اصلی را سرو می‌کند. برای روتینگ، از hash mode استفاده کنید یا فایل 404.html سفارشی بسازید.

❌ بسته gh-pages خطا می‌دهد

اگر با خطای مجوز مواجه شدید:

terminal 
# تنظیم نام کاربری و ایمیل گیت
git config user.name "YOUR-USERNAME"
git config user.email "YOUR-EMAIL@example.com"

# دوباره اجرا کنید
npm run deploy
